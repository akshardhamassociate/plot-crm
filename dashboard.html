Guide — Portal kaise chalayein

Yeh poora system kaise kaam karta hai — step by step. Koi bhi doubt ho to is page par wapas aa jaana.

Poora flow (ek nazar mein)

1Seller apni property /sell.html form se bhejta hai → listing Pending mein aati hai.

2Aap Stock / Listings mein jaakar Activate dabate ho → ab woh website par live dikhti hai.

3Buyer apni zaroorat website form se bhejta hai → Requirements mein aati hai (badge: Self / Website).

4Us requirement par Match & Send dabao → system milti-julti listings dikhata hai → choose karke buyer ko WhatsApp par bhej do.

Requirements (Buyer leads)

  • Self (Website) badge = buyer ne khud website form se bheja. Telecaller badge = aapke telecaller ne daala. (Yeh sirf batata hai lead kahan se aayi.)
  • Status: New (naya) → Contacted (baat ho gayi) → Matched (listing bhej di) → Closed (deal/band). Dropdown se badal sakte ho.
  • Match & Send dabate hi ek panel khulta hai jisme milti-julti active listings aati hain.

Match & Send — WhatsApp par kya jaata hai

  • Listings select karke Send → ek green WhatsApp button ban jaata hai. Dabate hi WhatsApp khulta hai, buyer ka number aur message pehle se bhara hota hai.
  • Message mein har property ke saath ek link jaata hai — buyer link dabaye to usse saari photos + map + rate dikh jaate hain.
  • Photo seedhe message mein abhi nahi jaati (WhatsApp ki paabandi). Chaaho to WhatsApp khulne ke baad khud photos attach kar sakte ho. (Aage WhatsApp Business API lagne par auto-photo bhi ho jayegi.)

Stock / Listings

  • Activate = Pending listing ko website par live karo. Mark Sold = bik gayi (website se hat jayegi). Re-activate = wapas live.
  • Edit = naam, rate, size, photos public/private, details sab badal sakte ho. (Galat rate yahin theek karo — jaise ₹ Lakh field mein sahi number.)
  • Delete (laal button) = listing hamesha ke liye hata do + uske match records bhi. Confirm poochega. Yeh wapas nahi aata — sambhal kar.

Baaki sections

  • Overview & Analytics — kitni listings, requirements, kahan se aa rahi hain (charts).
  • Match History — ab tak kaunsi listing kis buyer ko bheji gayi.
  • Field Feedback — team/ground se aayi feedback.
  • Add Property (Agent/Realtor) — aap khud bhi seedhe listing daal sakte ho (form bhare bina).
  • Telecaller Panel — telecaller ke liye alag page (buyer leads daalne ke liye).
